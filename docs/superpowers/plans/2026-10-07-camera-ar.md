# Camera AR Implementation Plan

> **For agentic workers:** Execute this plan inline, task by task, with test and verification checkpoints.

**Goal:** Add the previously proposed AR effects to the live camera and exported photos.

**Architecture:** Lazy, self-hosted MediaPipe models run in a dedicated worker. A shared canvas compositor draws accessories from normalized landmarks and replaces backgrounds using a person mask. Captures retain the original photo and a frozen AR snapshot, so the editor can disable AR without losing the photo.

**Tech Stack:** React, TypeScript, Canvas 2D, MediaPipe Tasks Vision 1.1.0, Vitest, Playwright, Cloudflare Pages.

## Global Constraints

- Keep the existing 80 frames and photo effects.
- Process camera frames locally; load model files only after selecting AR.
- Support mirror, countdown, burst, crop, rotation, undo, PNG and JPEG.
- Stop the worker on camera exit, hidden tab or AR off. Show a usable fallback on model failure.
- Verify Chromium and WebKit with real model inference before deployment.
